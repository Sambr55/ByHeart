# DUB — Pre-Test Master Experience Specification v0.6

> Verbatim-faithful working copy of the master spec, kept in the repo so the build
> can be checked against it. Section numbers match the source document.

**DUB — Find yourself in another language.**
Landing proposition + universal concept demo + five-question feedback spine.
European Portuguese.

THE EXPERIENCE IN ONE SENTENCE: DUB should feel like a cultural mixtape that quietly
turns into a conversation.

v0.6 fixes the first two beats — the DUB proposition landing page and the "Fala comigo,
Goose" concept demonstration — then hands cultural control to the learner. From that
point there is no privileged franchise.

## 01 What we are trying to prove

Not that famous quotes make learning more entertaining. That the familiar culture can
accelerate acquisition, improve recall and produce language that escapes its original
context.

CORE CONTENTION: if the learner already understands the human meaning of a moment, DUB
can attach a new language to an existing memory rather than asking the learner to build
meaning from scratch.

Four observable reactions: Recognition ("I know this"), Leverage ("that one thing just
gave me several things I can say"), Transfer ("I can use this even though the film has
disappeared"), Identity ("that sounds like something I would actually say").

## 02 The brand proposition

Landing page states the proposition before the learner does anything else. Immediately
after, DUB demonstrates the idea with one universally recognisable example — "Talk to
me, Goose." / "Fala comigo, Goose." — before asking the learner to choose their own
cultural starting point.

NAMING RULE: DUB is the brand, never the instruction. Do not use "DUB this", "DUB it",
"you DUBBED", "DUB Deck", "Daily DUB". Product actions belong to the learner: Your turn.
Make it yours. Things you can say. Your Portuguese.

## 02A Landing page + first concept demo

LANDING PAGE — EXACT COPY:

```
DUB
Find yourself in another language.

Start with something you already know.

Learn Portuguese through the films, music, TV, sport and culture already in your head.

Understand the moment.
Discover the language inside it.
Remix it. Use it. Make it yours.

You already know more than you think.

Primary CTA: SHOW ME HOW
```

The CTA does not open a lesson picker. It opens the concept demonstration. 30–45 seconds
total, brisk, visual, playful.

| Beat | Exact user-facing copy | Purpose |
| --- | --- | --- |
| 1. Recognition | TALK TO ME, GOOSE. / You already know what Maverick means. | Instant cultural recognition. No explanation yet. |
| 2. Translation | FALA COMIGO, GOOSE. / Talk to me, Goose. | Show the familiar thought living naturally in Portuguese. |
| 3. Extract | COMIGO = WITH ME / That one familiar line just gave you something useful. | Make the leverage visible. |
| 4. Build | Vem comigo. = Come with me. / Fica comigo. = Stay with me. / Podes vir comigo? = Can you come with me? | One recognised root becomes several things worth saying. |
| 5. Release | Your friend is leaving. Say: "Come with me." Answer: Vem comigo. | Remove Top Gun immediately and prove the phrase can travel. |

Demo close: "That's DUB. Start with something you already know. Find the useful language
inside it. Make it yours." Then move directly to the learner's cultural starting choice.

## 03 The design danger

FAILURE MODE: a culturally novel acquisition source wrapped around conventional
language-app mechanics is not enough. The learner should never spend more than roughly
60–90 seconds in a generic exercise state without a fresh recognition, subtext,
collision, personalisation or real-world-use moment. Culturally literate before
educational; conversational before curricular.

## 04 The operating idea

ROOT -> LANGUAGE -> SELF. A cultural mixtape rather than a course. A cultural root is
internal product language: a recognisable quote, title, moment, idea or piece of wisdom.
No cultural property is a silo.

## 05 The cultural root system

Every root must: trigger recognition; yield 1–3 high-frequency recombinable pieces;
branch into at least 3 things the learner could plausibly say; carry tone/subtext;
reinforce at least one previously acquired piece where possible; escape itself by ending
in a situation with nothing to do with the original culture.

Internal content rule: each new root should introduce 1 new high-value piece, reinforce 1
existing piece and unlock 3+ useful utterances.

## 06 The cultural heartbeat

1. Recognise (5–10s) · 2. Hear/see it differently (10–15s) · 3. Feel it — one line of
subtext (8–12s) · 4. Take it — 1–3 pieces pulled out (10–15s) · 5. Bend it — recombine
(15–25s) · 6. Choose it — learner picks the version they would use (10–20s) · 7. Release
it — cultural styling disappears (15–25s) · 8. Reappear later (5–15s).

MAGIC DENSITY RULE: every 60–90 seconds, a fresh point of cultural recognition, leverage,
collision, subtext, personalisation or no-cue competence.

## 07 The points of difference

1. Teach things worth saying, not vocabulary.
2. Make subtext part of the lesson — direct, teasing, formal, apologetic, dry, dramatic,
   warm, awkward. Technically accurate vs what a speaker would naturally say.
3. Make the root explode outward — one line visibly branches into 3–5 real things. A
   reveal, not a worksheet.
4. Make culture collide — after two or three roots, combine pieces from different worlds.
5. Begin building My Voice — "Which sounds more like you?" Store the choice; reflect a
   lightweight pattern after 3–5 signals.
6. Measure expressive power, not lesson progress — "You can now invite, refuse,
   apologise, ask someone to repeat themselves, explain what you need and make a plan."
7. Strip away the culture when it has done its job: full root -> subtle reference -> no
   reference -> free use.

ONE FIXED DEMO. NO FIXED CULTURAL PATH. Top Gun is never privileged in navigation,
analytics or copy. First root: always learner-chosen. Next roots: learner chooses from

After each root, return agency: a small "Where next?" set — one route that stays close to
current taste, one that changes the mood, one "Surprise me".

Picker copy: "WHAT DO YOU ALREADY KNOW BY HEART? / Type anything — or choose a place to
start." then "Or start somewhere here." and the six family cards.

## 10 Root-to-language templates

Freebies: 10–15 second cultural wink unlocking one genuinely useful piece. Recognition ->
natural Portuguese -> one takeaway -> move on. Max one freebie per cultural family per
session.

James Bond Film Titles: title-led with one deliberate freebie at the front ("My name
is… James Bond"). **Remove weak choices such as Skyfall.** Prioritise Tomorrow Never
Dies, From Russia with Love, Never Say Never Again, No Time to Die.

THE SEMANTIC BRIDGE IS MANDATORY. Before extracting any building blocks, show why this
Portuguese is a natural expression of the root's human meaning. The learner must trace:
ROOT -> NATURAL PORTUGUESE -> THESE PIECES.

ROOT QUALITY TEST: if removing the famous name leaves a weak or useless language lesson,
reject the root.

## 11 Culture collisions

Use at least two pieces from different roots. Prefer ordinary human situations. After
success, surface provenance subtly: "You met COMIGO earlier. AMANHÃ came from somewhere
else. Now they work together."

## 12 My Voice

Do not build a personality quiz. Collect signals invisibly through meaningful choices:
two natural options ("Which would you actually say?"), tone (dry/warm), register
(casual/polite), recovery (apologise/joke). After 3–5 signals reflect a light
observation: "We are beginning to get you. You tend to choose direct, dry language."
Tentative and useful, not psychological.

## 13 Progress as expressive power

"Things you can say" · "Your Portuguese" · "You can now invite, refuse, apologise, ask
someone to repeat themselves, make a plan and explain what you need." · "This one no
longer needs the original cue." · "These three are getting stronger." Cue cards are
phrase/action-led, not dictionary-led. Track root provenance internally but do not let it
dominate the user-facing object.

## 14 AI role and content selection

Preserve an obvious relationship between root and its natural Portuguese, explain the
bridge succinctly, then maximise leverage from pieces genuinely contained in that
expression. DO NOT OPTIMISE FOR completing a franchise, covering a grammar syllabus,
maximising new words, or showing off AI-generated content.

## 15 Rights-softening guardrails

Cultural reference as a memory trigger, not a media library. Short roots over long
dialogue. Paraphrase the moment where the situation matters more than the wording. Film
titles remain compact references; no implied endorsement. Verify attributed quotations.
Marcus Aurelius from public-domain/original-source meaning or DUB's own rendering. Store
content provenance and rights-review status in the content model so risky roots can be
swapped without breaking the curriculum.

## 16 Visual and interaction rhythm

Root arrival: give the cultural thought space — bold type, distinctive atmosphere,
minimal controls. Translation reveal: motion/typography making the Portuguese feel like a
transformation of meaning, not a subtitle. Extraction: pull pieces physically out of the
root, consistent building-block identity across worlds. Branch/remix: one phrase becoming
several. Collision: blend learned pieces. No-cue transfer: strip cultural styling
deliberately; the absence of culture is the point. My Voice: choice and reflection, not
scores. Progress: capability and retention, not mascots or XP.

## 17 What must be built before test

1. DUB landing page proposition copy exactly as specified.
2. Fixed Goose concept demo immediately after: recognition -> translation -> COMIGO
   extraction -> useful branches -> culture-free release.
3. Only after the demo, "What do you already know by heart?" + start-anywhere cultural
   selection. The demo must not create a forced Top Gun path.
4. Load the Appendix B seed content: at least 4 strong roots per family plus an optional
   freebie where specified.
5. `semantic_bridge` as a required content field between `pt_natural` and extracts;
   reject roots where the bridge is weak.
6. A `subtext` field and one-sentence "how this feels in use" reveal.
7. Root-explosion choreography: each strong root visibly unlocks 3+ usable expressions.
8. A "Where next?" choice after roots: stay close / change the mood / surprise me.
9. At least two cross-root or cross-moment collision opportunities in a 10-minute session.
10. Lightweight My Voice choice capture and one reflected voice insight after 3–5 signals.
11. Replace vocabulary/XP progress with "Things you can say" and expressive-power summary.
12. No-cue transfer sequence where cultural styling disappears.
13. Instrument cultural starting choice, next-root choice, root familiarity, first-attempt
    success, branch success, cross-root transfer, no-cue transfer, voice choices, final
    recall.
14. European Portuguese QA on every user-facing phrase, naturalness note and
    literal-vs-natural bridge.
15. Adversarial IP/content-source review; mark each root with provenance/rights status;
    keep risky roots swappable.
16. Roughly 10 minutes, but do not force a franchise order.

## 18 Testing and falsification

Measure: can they explain what DUB is without being told; what Portuguese they recall
without looking back; whether familiarity correlates with recognition/recall; whether
they combine pieces from different roots; whether they produce language after the cue has
gone; whether My Voice feels personal or gimmicky; whether they want another cultural
world; whether they would return to say more.

Rethink if: the root gets attention but does not improve retention or transfer; users
describe it as "Duolingo with film quotes"; collisions feel contrived; users remember the
reference but not the Portuguese; subtext slows without adding confidence; My Voice feels
presumptuous; the six families feel like unrelated content.

SUCCESS IS NOT "that was fun". Success is "that was different, I remember some of it, and
I can already imagine using it."

## 18A The silver thread

| Product beat | Claim tested | Evidence in app | Feedback closure |
| --- | --- | --- | --- |
| Landing proposition | DUB is a recognisably different way to learn | Can the learner understand the idea after experiencing it | Q1 |
| Goose demo + cultural roots | Familiar culture creates memorable hooks | Recognition -> translation -> extraction -> later recall | Q2 |
| Learner-chosen starting point | Personal familiarity improves comprehension and memory | Root familiarity, engagement, recall tracked | Q3 |
| Build -> collision -> no-cue release | The language becomes usable beyond the source | Learner succeeds after the cue disappears | Q4 |
| Whole 10-minute experience | The difference earns another session | Completion, choice behaviour, return intent | Q5 |

The "what culture next?" signal is captured through in-product cultural choices before
the form. Do not turn it into a sixth feedback question.

## 19 Feedback form — EXACTLY FIVE QUESTIONS

1. In one sentence, what do you think this product is? — free text
2. Without looking back, what Portuguese words or phrases can you remember? — free text
3. Did starting with something culturally familiar make the Portuguese easier to
   understand and remember? — 1–5
4. How confident do you feel that you could use something you just learned in a real
   conversation? — 1–5
5. Be brutal: what is the biggest reason you would NOT come back and use this again? —
   free text

No NPS, demographics, "what next?", optional "why?" fields or extra diagnostic questions.
Delayed recall runs as a separate research follow-up, not in the in-app form.

## 20 The non-negotiables

1. Culture is the learning mechanism, not the skin.
2. Teach things worth saying, not vocabulary for its own sake.
3. Every strong root should unlock several usable expressions.
4. Subtext matters.
5. No cultural property becomes a course silo.
6. Language from different roots must collide and compound.
7. The culture must eventually disappear; the language must remain.
8. Progress is expressive power.
9. My Voice should make "Find yourself in another language" true inside the product.
10. DUB is the brand. Never the instruction.
11. A 10-minute session should feel like a cultural mixtape, not a lesson plan.
12. The final emotional reward is competence: "You already know more than you think."
13. There is no default cultural franchise after the fixed Goose concept demo.
14. Every root must visibly follow ROOT -> NATURAL PORTUGUESE -> SEMANTIC BRIDGE ->
    EXTRACT -> BUILD -> RELEASE.
15. Freebies are earned cultural winks, not filler and not mini-lessons.
16. The order is non-negotiable: landing proposition -> Goose concept demo ->
    learner-chosen cultural starting point -> cultural mixtape -> no-cue transfer ->
    exactly five feedback questions.

THE HEART OF DUB: start with recognition. Turn recognition into leverage. Turn leverage
into your own language. Then let the cue disappear.

BUILD RULE: preserve the sequence cultural root -> natural Portuguese -> semantic bridge

### B3 Top Gun Quotes
Short quoted roots. Only the quoted line itself; no stills, audio, scene reproduction or
extended dialogue.

**FREEBIE / Talk to me, Goose.** — PT: *Fala comigo, Goose.*
Bridge: the urgency is intact; Portuguese expresses "with me" as COMIGO, attached
directly to the command FALA. Take: COMIGO = with me. Build: Vem comigo. / Fica comigo. /
Podes vir comigo? Subtext: direct, close, urgent. Release: your friend is walking away —
"Come with me." -> Vem comigo. Rights: short cultural quote; review required.

**ROOT 1 / You can be my wingman anytime.** — PT: *Podes ser o meu parceiro quando quiseres.*
Bridge: the aviation metaphor becomes natural human Portuguese; the useful pieces are
PODES and QUANDO QUISERES, not the military noun. Take: PODES = you can; QUANDO QUISERES
= whenever you want. Build: Podes vir comigo? / Podes dizer outra vez? / Quando quiseres.
Subtext: warm permission rather than formal ability. Release: a friend asks when they can
call — "Whenever you want." -> Quando quiseres.

**ROOT 2 / What were you thinking?** — PT: *Em que estavas a pensar?*
Bridge: Portuguese literally asks "in what were you thinking?" because PENSAR EM means
"to think about". Take: ESTAVAS A PENSAR = you were thinking; EM QUE…? = what … about?
Build: Em que estás a pensar? / Estava a pensar… / Estava a pensar em ti. Subtext: curious,
intimate or accusatory depending on tone. Release: someone goes quiet — "What are you
thinking about?" -> Em que estás a pensar?

**ROOT 3 / I feel the need…** — PT: *Sinto que preciso…*
Bridge: rather than carrying the English noun "need" across literally, natural Portuguese
turns the idea into the verb PRECISAR. Take: PRECISO DE = I need. Build: Preciso de ajuda.
/ Preciso de um táxi. / Preciso de tempo. Subtext: extremely useful, neutral everyday
language; DUB improving on subtitle literalism. Release: hotel reception — "I need a
taxi." -> Preciso de um táxi.

**ROOT 4 / I will not leave my wingman.** — PT: *Não vou deixar o meu parceiro.*
Bridge: the cultural meaning is loyalty; the reusable Portuguese is the future-intention
frame NÃO VOU + verb. Take: NÃO VOU = I am not going to; DEIXAR = to leave/let. Build:
Não vou sair. / Não vou amanhã. / Não vou fazer isso. Subtext: firm intention. Release:
asked if you are going out — "I'm not going." -> Não vou.

### B4 James Bond Film Titles + freebie
Title-led. Do not use a weak title simply because it is famous. **Skyfall is out: almost
no linguistic leverage.**

**FREEBIE / My name is… James Bond.** — PT: *Chamo-me… James Bond.*
Bridge: English says "my name is"; European Portuguese introduces yourself with CHAMO-ME
— literally "I call myself". Take: CHAMO-ME = my name is. Build: Chamo-me Sam. / E tu,
como te chamas? / Como se chama? Subtext: culturally unmistakable and immediately useful.
Release: you meet someone new -> Chamo-me Sam.

**ROOT 1 / Tomorrow Never Dies** — PT: *Amanhã nunca morre.*
Bridge: the title is compact and both useful pieces survive intact. Take: AMANHÃ =
tomorrow; NUNCA = never. Build: Até amanhã. / Amanhã não posso. / Nunca mais. Subtext:
time + absolute frequency in one recognisable title. Release: asked whether today works —
"Tomorrow." -> Amanhã.

**ROOT 2 / From Russia with Love** — PT: *Da Rússia com amor.*
Bridge: the useful engine is COM = with. Take: COM = with; AMOR = love. Build: Café com
leite. / Com açúcar? / Comigo. (COM + MIM becomes COMIGO.) Subtext: compact root that
reinforces COMIGO from Top Gun while teaching the general COM. Release: order coffee
"with milk" -> Café com leite.

**ROOT 3 / Never Say Never Again** — PT: *Não digas "nunca" outra vez.*
Bridge: natural Portuguese expresses the title as "don't say 'never' again", giving NUNCA
and OUTRA VEZ in one memorable thought. Take: NUNCA = never; OUTRA VEZ = again; NÃO DIGAS
= don't say. Build: Diz outra vez. / Podes dizer outra vez? / Nunca mais. Subtext: playful
and unusually useful. Release: you did not hear the waiter -> Podes dizer outra vez?

**ROOT 4 / No Time to Die** — PT: *Sem tempo para morrer.*
Bridge: SEM = without and TEMPO = time are directly visible; PARA introduces purpose.
Take: SEM = without; TEMPO = time; PARA = for/to. Build: Sem açúcar. / Sem gelo. / Não
tenho tempo. Subtext: useful travel language from a dramatic title. Release: at the bar,
ask for it "without ice" -> Sem gelo.

### B5 Bridget Jones Cringe Moments
Paraphrased social situations, not a screenplay quote bank.

**FREEBIE / You overshare. There is now a silence.** — PT: *Falei demais.*
Bridge: the cringe is "I said too much"; Portuguese compresses that into FALEI DEMAIS.
Take: DEMAIS = too much; FALEI = I spoke. Build: Desculpa, falei demais. / Comi demais. /
Bebi demais. Subtext: self-aware, human, lightly comic. Release: you have been talking for
five minutes -> Falei demais.

**ROOT 1 / You arrive late. Everyone is already there.** — PT: *Desculpa o atraso.*
Bridge: the useful social repair is the phrase a Portuguese speaker would actually reach
for: "sorry for the delay." Take: DESCULPA = sorry; ATRASO = delay. Build: Desculpa. /
Desculpa o atraso. / Peço desculpa. (more formal) Subtext: warm everyday repair; register
can become a My Voice choice. Release: ten minutes late for lunch -> Desculpa o atraso.

**ROOT 2 / You forget the name of the person you are talking to.** — PT: *Desculpa… como te chamas?*
Bridge: apologise lightly, then ask the name directly. Take: COMO TE CHAMAS? = what's your
name?; DESCULPA = sorry. Build: Chamo-me Ana. / Como te chamas? / Como se chama? Subtext:
embarrassing but recoverable; reinforces the Bond CHAMO-ME freebie. Release: you meet
someone and want their name -> Como te chamas?

**ROOT 3 / You say the wrong thing while trying to impress someone.** — PT: *Desculpa. Não era isso que queria dizer.*
Bridge: Portuguese social repair works as "Sorry. That wasn't what I meant to say." Take:
NÃO ERA ISSO = that wasn't it; QUERIA DIZER = I meant. Build: Queria dizer… / Não era
isso. / Desculpa, queria dizer outra coisa. Subtext: gives permission to recover instead
of freeze. Release: you use the wrong word -> Desculpa. Não era isso que queria dizer.

**ROOT 4 / The joke does not land.** — PT: *Era uma piada.*
Bridge: instantly recoverable with the simple past frame ERA UMA… = it was a… Take: ERA =
it was; UMA PIADA = a joke. Build: Era uma piada. / Estou a brincar. / É uma piada?
Subtext: "Era uma piada" can be sheepish; "Estou a brincar" is lighter. Release: your
friend takes you seriously -> Estou a brincar.

### B6 Pulp Fiction Banger Quotes
Keep exact quoted material tiny. Preserve the punch, then leave the movie fast.

**FREEBIE / Royale with Cheese.** — PT: *Royale com queijo.*
Bridge: the joke is cultural; the useful word is COM = with. Take: COM = with. Build: Com
açúcar. / Com gelo. / Com queijo. Subtext: a fast wink, not a lesson. Release: order
something "with cheese" -> Com queijo.

**ROOT 1 / Say "what" again!** — PT: *Diz "o quê" outra vez!*
Bridge: the rhythm carries cleanly. Take: DIZ = say; O QUÊ? = what?; OUTRA VEZ = again.
Build: Diz outra vez. / Podes dizer outra vez? / O quê? Subtext: the film gives the phrase
aggression; DUB shows the polite usable version as the thing to keep. Release: you miss
what someone said -> Podes dizer outra vez?

**ROOT 2 / That's a tasty burger.** — PT: *Esse hambúrguer é mesmo bom.*
Bridge: a literal "saboroso" is possible, but everyday European Portuguese says "é mesmo
bom". Take: MESMO = really; BOM = good; ESSE = that. Build: Isso é mesmo bom. / Muito bom.
/ Esse é bom. Subtext: natural speech beats dictionary fidelity. Release: taste something
excellent -> Isso é mesmo bom.

**ROOT 3 / Be cool.** — PT: *Tem calma.*
Bridge: Portuguese is more likely to say "have calm" than translate "cool" literally.
Take: TEM CALMA = calm down; CALMA = calm/easy. Build: Calma. / Tem calma. / Está tudo
bem. Subtext: TEM CALMA can soothe or irritate depending on delivery; CALMA is softer.
Release: a friend is panicking -> Calma.

**ROOT 4 / The Quarter Pounder conversation — what do they call it?** — PT: *Como é que se chama?*
Bridge: the memorable scene is about what something is called. Take: COMO É QUE SE CHAMA?
= what is it called? Build: Como se chama isto? / Como te chamas? / Chama-se… Subtext:
Pulp Fiction unexpectedly becomes survival language. Release: point at unfamiliar food ->
Como se chama isto?

### B7 Audrey Hepburn Musings
Not a quote archive. Clearly labelled paraphrased musings.

**FREEBIE / Paris is always a good idea.** — PT: *Paris é sempre uma boa ideia.*
Bridge: maps cleanly and gives two useful pieces. Take: SEMPRE = always; BOA IDEIA = good
idea. Build: É uma boa ideia. / Sempre. / Acho que é uma boa ideia. Subtext: elegant, warm,
instantly usable; provenance must be checked. Release: a friend suggests lunch outside ->
Boa ideia.

**ROOT 1 / Musing: Enjoy your life.** — PT: *Aproveita a vida.*
Bridge: a documented Audrey theme becomes a compact imperative. Take: APROVEITA = enjoy;
VIDA = life. Build: Aproveita o dia. / Aproveita! / Quero aproveitar. Subtext: positive
without being saccharine. Release: your friend leaves for a holiday -> Aproveita!

**ROOT 2 / Musing: People matter more than things.** — PT: *As pessoas importam mais do que as coisas.*
Bridge: the human idea is a comparison, making MAIS DO QUE the reusable engine. Take: MAIS
DO QUE = more than; IMPORTAM = matter. Build: Tu importas. / Mais do que isso. / Isto
importa. Subtext: warm, emotionally useful rather than phrasebook. Release: tell someone
"You matter." -> Tu importas.

**ROOT 3 / Musing: Look for the good in people.** — PT: *Procura o lado bom das pessoas.*
Bridge: built around LADO BOM and PROCURA. Take: PROCURA = look for; LADO BOM = good side.
Build: Procura aqui. / O lado bom. / É uma boa pessoa. Subtext: gentle but active.
Release: asked what you like about a situation -> O lado bom.

**ROOT 4 / Musing: The most important thing is to be happy.** — PT: *O mais importante é ser feliz.*
Bridge: O MAIS IMPORTANTE É… is reusable far beyond the sentiment. Take: O MAIS IMPORTANTE
= the most important thing; SER FELIZ = to be happy. Build: É importante. / O que é mais
importante? / Quero ser feliz. Subtext: aspirational language that still produces everyday
structures. Release: say "It's important." -> É importante.

### B8 Marcus Aurelius Wisdom
Public-domain source meaning or DUB-authored distillation. Never lift a modern copyrighted
translation.

**FREEBIE / Control what you can control.** — PT: *Controla o que podes controlar.*
Bridge: wisdom and Portuguese are nearly structurally identical, making PODES immediately
visible. Take: PODES = you can; CONTROLAR = to control; O QUE = what. Build: O que posso
fazer? / Não posso controlar isso. / Podes controlar isto. Subtext: calm, practical,
modern-sounding despite the ancient root. Release: ask yourself "What can I do?" -> O que
posso fazer?

**ROOT 1 / Wisdom: You do not control what happens. You control how you react.** — PT: *Não controlas o que acontece. Controlas como reages.*
Bridge: the idea splits into EVENT vs RESPONSE. Take: O QUE ACONTECE = what happens; COMO
= how; REAGES = you react. Build: O que aconteceu? / Como reagiste? / Não posso controlar
isso. Subtext: a reflection root that unlocks very ordinary questions. Release: ask
someone "What happened?" -> O que aconteceu?

**ROOT 2 / Wisdom: The only moment you have is now.** — PT: *O único momento que tens é agora.*
Bridge: makes AGORA memorable while TENS becomes available for ordinary use. Take: AGORA =
now; TENS = you have. Build: Agora não. / E agora? / Tens tempo? Subtext: the wisdom
disappears quickly; AGORA and TENS remain practical. Release: someone asks if you can talk
-> Agora não.

**ROOT 3 / Wisdom: If it is not true, do not say it.** — PT: *Se não é verdade, não digas.*
Bridge: gives SE, VERDADE and the useful negative command NÃO DIGAS. Take: SE = if; É
VERDADE = it is true; NÃO DIGAS = don't say. Build: É verdade? / Se quiseres. / Não digas
isso. Subtext: simple moral language converting into everyday conditionals. Release: ask
"Is it true?" -> É verdade?

**ROOT 4 / Wisdom: Accept what you cannot change.** — PT: *Aceita o que não podes mudar.*
Bridge: two reusable engines, NÃO PODES and MUDAR. Take: NÃO PODES = you can't; MUDAR = to
change; ACEITA = accept. Build: Posso mudar isto? / Não posso mudar isso. / Quero mudar.
Subtext: reflective root, practical language; reinforces PODES. Release: asked to alter a
booking -> Posso mudar isto?

### B10 Freebie rules
Recognisable in under two seconds. Unlocks one useful piece or reinforces one already
learned. 10–15 seconds, not a mini-lesson. No quiz. Max one per family per session. Can
break the formal root type when the value is exceptional. If it exists only because it is
funny or famous, remove it.

### B11 Content implementation note
The appendix is a seed graph, not a fixed sequence. A user might begin with Marcus, move
to Bridget, choose Bond next and never see Top Gun at all. That is a success condition,
not an edge case.
